What we do

Keep the software you depend on. Lose the limitations.

Great software shouldn't die because its platform did. We extend its life without starting over.

Platforms & runtimes

Cross-platform porting

Software tied to one operating system, brought to Windows, macOS, and Linux, in whichever direction you need, without losing the behavior your users rely on.

Dead runtimes & frameworks

Visual Basic 6, Delphi, PowerBuilder, Classic ASP, Flash, Java applets, and old .NET Framework versions, moved onto supported, current technology.

Compatibility fixes

Won't run on new hardware or a current OS version, or only as a 32-bit app? We resolve runtime and dependency problems so it works again.

Data & databases

Database modernization

Microsoft Access, FoxPro, dBase, Paradox, FileMaker, and Lotus Notes applications migrated to modern engines like PostgreSQL, SQL Server, and MySQL, with schemas, queries, forms, and reports carried forward.

Spreadsheet & macro rescue

Business processes running on giant Excel workbooks and VBA macros, rebuilt on a real database and application that's reliable, auditable, and multi-user.

File formats & reporting

Proprietary and undocumented formats, EDI feeds, and fixed-width exports converted to open standards, with old Crystal Reports-style reporting replaced by modern reports and dashboards.

Integration & specialty systems

Interoperability & APIs

Old systems with no way to connect to anything new get modern APIs, wrappers, and clean integrations with the tools you use today.

Hardware & driver dependence

Instrument, lab, and industrial control software that depends on serial/COM ports, USB drivers, or 32-bit DLLs, kept working on current systems.

Mainframe & COBOL

Assessment and migration of long-running mainframe and COBOL business logic to modern platforms, with the rules your business depends on preserved.

Security & operations

Security remediation

Outdated libraries, hardcoded credentials, unencrypted data, and unsupported runtimes, audited and fixed, with a software bill of materials (SBOM) for customers and auditors who ask.

Build & source recovery

Code that only compiles on one person's machine? We recover the build, add version control and automated builds, and write the documentation. We can also work from compiled software where you hold the rights.

Containers & virtualization

When a full port isn't worth it, we run legacy software safely in a container or virtual machine, isolated, repeatable, and easy to back up.

Relaunch & reach

Sellable & supportable again

Customers still want it, but it's too old to sell or support. We make legacy products shippable and maintainable again.

Installers & distribution

Modern installers, automatic updates, and code signing, so your software installs cleanly and customers trust it.

Desktop to web & cloud

Single-user desktop applications reworked as browser-based or hosted versions, scoped carefully so it stays far short of a full rewrite.
